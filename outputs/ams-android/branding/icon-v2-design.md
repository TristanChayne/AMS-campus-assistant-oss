# 第二版图标

参考 skill：https://github.com/chunkithwang/design-playful-app-icons

路线：minimal dimensional glyph。隐喻：折页课表 + 到课对勾。配色：校园蓝 #172e61、暖白 #F8F6F5、浅蓝 #78C9F4。

概念候选（产品含义/轮廓/原创性，各5分，主观设计比较）：校园通行卡 4/4/3；折页课表 5/5/4；到课书签 3/4/4。选折页课表，能兼顾课表与签到。

视觉评估：整体轮廓与对勾清晰，实体面积比上一版更大；小尺寸下浮雕细节预计减弱。尚未实际进行32px栅格检查或Android桌面遮罩验证，不能作为已验收的自适应图标包。需要拆分前景背景并调整安全区后再接入APK。
