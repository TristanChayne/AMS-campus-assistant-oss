# iOS 交互核查

现有课表、卡片与配色可以保留。需要适配的是导航层级、返回手势、安全区域、字体与动态效果，无需整体重写为 SwiftUI。

本轮实现：底部 UIKit 导航与网页滚动分离；保留主页面系统回弹，仅将底部导航固定在滚动区域之外；加载状态只对真实文档跳转开启，网页就绪后恢复显示；签到记录、设置等内部页面统一方向明确的短动画，支持减少动态效果与快速切换取消；讨论室优先采用学校时间字段，色块与下方明细共用时段数据并标号对应。保留学校预约确认与阻挡重复操作的遮罩。

验证：Xcode 模拟器编译通过；就绪脚本、精确时间/结束预约过滤/宽度变化/坐标回退、动画方向/取消/减少动态效果、内嵌脚本语法检查通过。滚动手感与持续帧率尚需实际操作验证，不能仅凭编译认定通过。临时布局采样定时器已移除。

后续美化优先顺序：统一返回按钮和页面标题；增加小字对比度与可点击区域；适配系统字号；减少密集卡片边框。建议先完善交互再考虑材质与装饰动画。

已检索的技能候选（未安装）：
- [Apple Design Skill](https://github.com/dickwu/apple-design-skill)：跨框架审核，适合当前 UIKit + WKWebView；社区内容需与 Apple 官方指南交叉核对。
- [SwiftUI Interface Design Skill](https://github.com/ZHUOLIN0928/swiftui-interface-design-skill)：适合未来原生 SwiftUI 页面，不宜直接作为现有网页移植代码的实施规范。

动画依据：[Apple Motion 指南](https://developer.apple.com/design/human-interface-guidelines/motion)。动画应说明关系与操作结果，支持减少动态效果；频繁操作不需要增加装饰性动画。


## 已实施的固定布局、预加载与 UI 改良

- 主页面标题、返回、设置与西浦码入口改用固定系统导航栏；底部保留独立系统导航。网页只承载中间内容，保持系统回弹，回弹背景与当前主题一致，不逐帧同步位置。
- 课表登录就绪后，延迟两秒开始准备座位页面，完成后再延迟两秒准备讨论室。最多保留两个网页实例；点击复用原实例。提前点击也复用同一个实例，避免重复创建。校车和预约记录按需打开。
- 预约入口显示真实的准备、可打开、需要登录、失败状态。预加载只准备页面；选择地点后读取学校最新占用。曾进入过的缓存页面在无确认弹窗时回到地点选择，避免沿用旧的空闲列表。
- 后台取消未使用的预加载；内存压力释放未展示的缓存；退出登录或进入学校重新认证时释放旧页面。隐藏时暂停 AMS、座位、讨论室、预约记录适配器的定时检查；系统和学校脚本的实际资源使用仍需性能测量。
- 设置分为外观、校园服务、关于、账户；退出登录放到账户组。修正 iOS 版本显示，统一二级返回入口。
- 收紧课表顶部与无课占位；调整记录汇总间距、正文大小和行距、按钮触控区域。主要文字响应系统字号（上限两倍），保持原有配色和课程卡片。
- 讨论室色块与文字明细共享时间数据；短时段可从文字明细点选，显示准确起止时间。占用、关闭或不足最短时长的时段不允许提交。补齐预约首页深色标题对比度。

验证：模拟器实际显示了固定标题栏、设置分组和真实预加载状态；讨论室预加载后直接展示已适配页面。Xcode 构建、脚本语法与就绪/时间/动画定向检查、真实预加载调度代码的实例复用/取消/内存释放/过期回调/提前点击检查通过。尚未测量真机 FPS、功耗或服务器响应耗时，不承诺所有预约入口零等待。测试没有提交真实预约。

Debug 的 --test-interface 模式提供事件驱动的测试入口及不含账户的状态快照，不使用持续采样；普通启动及 Release 不开启这些测试入口。
