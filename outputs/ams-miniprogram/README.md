# AMS 原生小程序适配版 0.2.4

导入本目录到微信开发者工具，AppID 沿用已有验证项目，保持域名校验开启。
request 域名：ams.xjtlu.edu.cn、portalapp.xjtlu.edu.cn、uim.xjtlu.edu.cn（HTTPS）。

没有演示数据回退。未知响应明确提示，真机新页面与分页尚待验收。
